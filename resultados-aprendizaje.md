> 📝 **Esta unidad prepara el RA1, pero no lo evalúa.** Para construir interfaces gráficas en la UD3 hace falta un lenguaje: esta unidad te da el C# necesario, siempre con programas de consola. Todos los criterios de evaluación del RA1 se evalúan en la **UD3**. Aquí los ejercicios son de autocorrección y no llevan nota.

## Resultado de aprendizaje

**RA1.** Genera interfaces gráficos de usuario mediante editores visuales utilizando las funcionalidades del editor y adaptando el código generado.

## Criterios de evaluación

Se evalúan todos en la UD3. La última columna indica qué prepara esta unidad.

| CE | Criterio de evaluación | En esta unidad |
|----|------------------------|----------------|
| a | Se han analizado las herramientas y librerías disponibles para la generación de interfaces gráficos. | El ecosistema .NET: entornos, bibliotecas y paquetes NuGet |
| b | Se ha creado un interfaz gráfico utilizando las herramientas de un editor visual. | Visual Studio: soluciones, proyectos y plantillas |
| c | Se han utilizado las funciones del editor para ubicar los componentes del interfaz. | — |
| d | Se han modificado las propiedades de los componentes para adecuarlas a las necesidades de la aplicación. | Las **propiedades** de C#, que son las de los controles |
| e | Se ha analizado el código generado por el editor visual. | Leer C#: clases parciales, *namespaces*, constructores |
| f | Se ha modificado el código generado por el editor visual. | Escribir C# con las convenciones del lenguaje |
| g | Se han asociado a los eventos las acciones correspondientes. | **Eventos, delegados y lambdas**: el mismo mecanismo que usan los controles |
| h | Se ha desarrollado una aplicación que incluye el interfaz gráfico obtenido. | El **modelo del dominio** (paso 1 del proyecto) sobre el que se construirá la aplicación |

## Contenidos básicos

Del bloque «Confección de interfaces de usuario» del RA1, esta unidad trabaja:

- Clases, propiedades, métodos.
- Eventos; escuchadores.

Y, como base para el resto:

- El lenguaje C# y la plataforma .NET.
- Colecciones, consultas sobre datos (LINQ) y programación asíncrona.
- Depuración, documentación y pruebas del código.
